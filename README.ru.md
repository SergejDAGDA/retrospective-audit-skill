# Retrospective Audit

[English version](README.md)

Универсальный по формату Agent Skill для аудита других навыков по фактической истории задач Codex Desktop.

Он помогает находить расхождения между тем, что написано в `SKILL.md`, и тем,
как работа фактически выполняется: пропущенные шаги, повторяющиеся repair-циклы,
ручные исправления, устаревшие правила, недостающие stop-lines и полезные
отклонения, которые стоит закрепить в навыке.

**GitHub-репозиторий:** `SergejDAGDA/retrospective-audit-skill`.

**Имя установленного навыка:** `retrospective-audit` (каталог `skills/retrospective-audit/`, вызов `$retrospective-audit`). Суффикс `-skill` относится только к GitHub-репозиторию. Прежнее имя `retrospective-skill-audit` относится к старым релизам и **не является действующим алиасом**.

**Версия пакета:** `0.2.0`. Факт публикации GitHub Release и установки необходимо проверять отдельно. Для анализа используется история задач Codex Desktop; поддержка других агентов не заявлена как проверенная.

## Что делает навык

- Читает целевой `SKILL.md`.
- Находит релевантные прошлые задачи Codex Desktop.
- Показывает кандидатов перед глубоким чтением.
- Ждёт согласования выборки пользователем.
- Читает выбранные истории задач.
- Раскладывает навык на проверяемый контракт.
- Сравнивает контракт с фактическим поведением в задачах.
- Отделяет устойчивые паттерны от единичных исключений.
- Выдаёт рекомендации и patch-план.

По умолчанию аудит read-only. Навык не должен менять skills, файлы, Git,
задачи Codex или внешние системы без отдельного явного подтверждения.

## Когда использовать

Запускайте навык после:

- 5-10 реальных применений конкретного навыка;
- повторяющихся ручных исправлений;
- повторяющихся неудачных repair-циклов;
- заметного изменения процесса;
- подготовки навыка к новому release;
- решения, стабилен ли навык в текущем виде.

Не стоит запускать его после одной нетипичной задачи. Меньше трёх независимых
примеров навык должен считать слабым сигналом, а не устойчивым паттерном.

## Установка

Установите навык через стандартный механизм установки Codex skills из этого
репозитория или скопируйте папку вручную:

```powershell
Copy-Item -Recurse `
  .\skills\retrospective-audit `
  $env:USERPROFILE\.codex\skills\retrospective-audit
```

После установки откройте новую задачу Codex, чтобы список навыков обновился.

## Базовый промпт

```text
Используй $retrospective-audit.

Проведи read-only аудит навыка:
<PATH_TO_SKILL.md>

Сначала найди релевантные прошлые задачи Codex Desktop, покажи кандидатов и
дождись моего согласования выборки. Не меняй файлы, Git, навыки, задачи Codex и
внешние системы.
```

## Промпт для Skill Lab

Для постоянного чата по обслуживанию навыков:

```text
Это мой Codex Skill Lab.

Покажи мои установленные пользовательские навыки из:
%USERPROFILE%\.codex\skills

Если задан CODEX_HOME, используй:
%CODEX_HOME%\skills

Отдели пользовательские навыки от системных и сторонних. Для каждого навыка
покажи: название, назначение, путь к SKILL.md и наличие agents/openai.yaml,
references или scripts.

Ничего не меняй без отдельного подтверждения.
Если я выберу навык для аудита, используй $retrospective-audit.
Если после аудита я одобрю правки, используй $skill-creator для обновления
навыка.
```

**Миграция с v0.1.1:** В прежних выпусках использовались `$retrospective-skill-audit` и каталог `skills/retrospective-skill-audit/`. Нельзя оставлять оба идентификатора одновременно активными. При отдельной установке нужно сохранить прежний пакет для отката, установить новый ID, проверить обнаружение в новом чате Codex Desktop и только после этого вывести старый активный каталог из использования. Репозиторий ничего автоматически не удаляет.

## Статус проверки

Этот навык можно проверить структурно без доступа к истории задач. Полная
поведенческая проверка требует реальных задач Codex Desktop и согласованной
пользователем выборки. Это намеренное ограничение: аудит должен опираться на
evidence, а не на симуляцию ожиданий.

## Связанные навыки

- `maintain-project-memory`: ведёт долговременную память проекта.
- `retrospective-audit`: поддерживает качество самих навыков.

Вместе они образуют небольшой организационный набор для ведения проектов и
процессов.
